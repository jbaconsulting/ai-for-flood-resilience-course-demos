# 2025s9274 - AI for Flood Resilience Course Demos
This repository contains the notebooks and data for demonstrating the applications of AI in JBA Consulting's **AI for Flood Resilience** course.

## How to Use
This repository uses [Binder](https://mybinder.org/) to open notebooks in a temporary JupyterLab instance.

👉 [Launch in Binder](https://mybinder.org/v2/gh/jbaconsulting/ai-for-flood-resilience-course-demos/HEAD?urlpath=%2Fdoc%2Ftree%2Fnotebooks%2F) 

Binder will build a Docker image of the repository with a JupyterLab instance, allowing the end user to access the code, with the environment preloaded for easy usage and reproducibility.

## Repository Structure
### `./data/`
Contains the relevant "dummy" data used in the notebooks. This primarily includes the SQLite database used for the associated AI chatbot demonstration. The data has been constructed to reflect realistic formats and structures commonly encountered in flood-related projects.

### `./notebooks/`
Contains the notebooks used to demonstrate the potential applications of AI in Flood Resilience. This directory includes examples showing:
- Semantic Similarity and Bias
- AI chatbot for a complex Climate Projections Database
Each notebook is designed to be self-contained and reproducible, allowing users to explore AI methods in a controlled and educational environment.

## About
These demos form part of JBA Consulting’s **AI for Flood Resilience** course, which explores how artificial intelligence can support flood risk management, resilience planning, and decision-making.

The notebooks are designed to be **interactive and educational**, demonstrating practical applications of AI based on real-world project workflows undertaken by JBA. Each example is grounded in realistic scenarios, showing how techniques such as machine learning, geospatial analysis, and predictive modelling can be applied in the context of environmental risk.

Although all data used in the demos is **fictional**, it has been carefully constructed to reflect the types of datasets typically used in flood-related projects. This ensures the exercises remain relevant, reproducible, and safe to share.
